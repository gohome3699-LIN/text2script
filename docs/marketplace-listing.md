### 商品简介（建议 120 字内）

> 把一段纯文本故事直接变成可拍摄的短剧方案：自动识别一句话创意/梗概/大纲/小说片段，
> 拆集并生成每集钩子，输出包含景别、运镜、转场、情绪与音调术语的分镜表。
> 纯本地规则引擎，不联网、不调 API；**输入语言自动匹配输出**（中文→中文、英文→英文），
> 支持 Markdown / JSON / 纯文字档 .txt。

### 功能亮点（bullet，建议 4–6 条）

- 四种输入类型自动识别：一句话创意 / 故事梗概 / 大纲分卷 / 小说片段
- 一条命令完成「文转剧本 → 拆集钩子 → 角色关系 → 分镜拆解」全链路
- 分镜术语标准化：景别（远景/全景/中景/近景/特写）、6 类运镜、10 类转场、11 类情绪/音调
- 集末钩子：悬念 / 反转 / 新信息 / 冲突升级等类型自动标注
- 台词归属：支持中文引号（“ ” 与「」）对话，长文本自动分段
- 语言自动匹配（v1.2.0）：中文输入 → 中文剧本/分镜；英文输入 → 英文剧本/分镜（英文术语与模板），覆盖海外创作者
- 输出可编程：JSON 结构清晰，便于接入脚本与批量处理

### 详细描述（建议 300–500 字）

text2script 把「创意 → 分镜」的最耗时环节压缩为一条命令。适合短剧编剧、小说作者、
短视频创作者、内容团队批量评估故事的可拍性。

工作流：输入解析（类型识别、文本清洗、红线提示、长文本自动分段）→ 拆集与集末钩子 →
角色关系 → 分镜拆解（每镜含景别、运镜、转场、情绪、表情、音调、时长）。

输出形态：Markdown 分集剧本 + 分镜表，或结构化 JSON。可用 `--duration`（60–90 秒/集）
与 `--shots-per-minute`（18–22 镜/分钟）控制成片节奏。

安全合规：内置 7 类红线清单（血腥暴力/低俗擦边/恐怖灵异/封建迷信/侮辱群体/虚假宣传/
真人肖像），命中时明确提示人工复核，不代替判断。

## 3. 能力边界（审核/FAQ 用）

- 只做文本 → 剧本/分镜：**不生成视频、图片、音频**。
- 纯本地规则引擎：不联网、不调用外部 AI 服务，仅 Python 标准库。
- 输入语言匹配输出（v1.2.0）：中文输入 → 简体中文输出；英文输入 → 英文输出；网页版界面三语（简/繁/EN）仅切换 UI 文案，不翻译内容。
- 枚举硬约束：景别、运镜、情绪、钩子类型、场景时段枚举固定，不随输入新增。
- 免责声明：不保证生成内容完全可用；命中红线类别的输出需人工复核。
