## 2. 完整口播稿（可直接照着念）

做短剧或者改小说的时候，最烦的一步是什么？——把文字变成分镜。

今天给你一个免费开源工具：一句话、一段梗概、甚至一整篇小说片段，都能变成分集剧本和分镜表。

比如这一句剧情：外卖小哥获得读心术后，在送餐途中识破一场针对富豪的绑架阴谋。直接丢给它。

它自动拆集、写钩子、出角色，最后给到每一条分镜：景别、运镜、转场、情绪、音调，全都有。

小说片段、Word 文档也一样能输入，自动识别类型、自动分段，长文本也不会丢。

要接程序，就输出 JSON，钩子、台词、分镜都能当数据用。

它会内置红线检测，碰到敏感内容会提示人工复核——这个很关键。

工具自带一百六十一条测试，纯本地运行，不联网不用 API，免费开源。

想用的话，去 GitHub 搜 text2script，MIT 协议随便拿去用。觉得有用，一键三连支持一下。

## 3. 演示操作清单（录制前完整跑一遍）

```bash
# 01 版本
python text2script.py --version

# 02 一句话创意
python text2script.py --text "外卖小哥获得读心术后，在送餐途中识破一场针对富豪的绑架阴谋"

# 03 文件模式（小说片段，含对话与「」引号）
python text2script.py --file examples/input-2-synopsis.txt

# 04 JSON + 写入文件
python text2script.py --file examples/input-3-outline.txt --format json --output /tmp/demo.json
python - <<'PY'
import json; d=json.load(open('/tmp/demo.json'))
print('集数:', len(d['episodes'])); print('第一集钩子:', d['episodes'][0]['episode_hook'])
PY

# 05 红线提示（恐怖灵异素材）
python text2script.py --file trials/trial-06-excerpt.txt 2>&1 | grep -o "命中红线类别.*" || true

# 06 全量测试
python -m unittest discover -s . -p "test_*.py"
```

> 演示用文件路径需在 text2script/ 目录内执行；若演示素材文件名不一致，以本地实际为准。
