# text2script 赞助渠道配置指引（T27）

> 目标：在开源页（GitHub README）配置三渠道收款入口——**GitHub Sponsors / 爱发电 / Patreon**，
> 形成「开源信任 → 教程流量 → 付费/赞助」闭环（开发清单第六节）。
> 三渠道均需创作者本人注册并实名/绑卡，故本指引给到「入口 + 步骤 + 链接格式 + 嵌入 README 的写法」，
> 注册与收款信息请按各平台官方要求填写。

---

## 1. 渠道对比（选型参考）

| 渠道 | 适配人群 | 主要优势 | 到账方式 | 沙箱可达性验证 |
| --- | --- | --- | --- | --- |
| GitHub Sponsors | 开源项目作者 | 与仓库天然一体，星标用户顺手赞助；平台免手续费（支付通道费另算） | Stripe/PayPal，按账号地区税务要求 | 沙箱不可达（网络限制），官方入口 https://github.com/sponsors |
| 爱发电 | 中文内容创作者 | 国内用户支付无墙；支持月费会员制；适合 B 站/抖音粉丝引流 | 微信/支付宝 | ✅ 官方入口 https://afdian.com 可达（HTTP 200） |
| Patreon | 面向海外用户 | 月订阅模式成熟；适合英文教程/海外博主引流 | Stripe/PayPal | 沙箱不可达（网络限制），官方入口 https://www.patreon.com |

**建议组合：** 国内流量（B 站/抖音/技能市集）主推 **爱发电**；海外与 GitHub 流量用 **GitHub Sponsors**；如后续有英文教程再补 **Patreon**。首期只需配前两个。

---

## 2. GitHub Sponsors 配置

1. 打开 https://github.com/sponsors ，按页面指引提交开通申请（需 GitHub 账号；按官方要求完成税务与银行/支付信息）。
2. 通过后，你的赞助主页链接格式为：`https://github.com/sponsors/<你的GitHub用户名>`。
3. 在仓库 README「赞助与支持」章节填入该链接（写法见第 5 节）。

> 说明：GitHub Sponsors 开通需账号满足官方条件（活跃账号、非封禁状态等），具体以
> [GitHub Docs](https://docs.github.com/zh/sponsors) 为准；若暂不满足条件，可先只配爱发电。

## 3. 爱发电配置（推荐首期启用）

1. 注册并登录 https://afdian.com （✅ 本机已验证主站可达）。
2. 创建「发电页面」/ 创作者主页，设置月费档位（建议 3 档：如 6 / 19 / 49 元，对应「支持维护 / 投喂咖啡 / 进阶答疑」）。
3. 主页链接格式：`https://afdian.com/a/<你的爱发电uid>`（uid 在个人主页 URL 中）。
4. 在 README「赞助与支持」章节填入该链接。

> 爱发电支持设置「免费 + 付费」内容；可把教程、示例、分镜进阶技巧作为发电福利，放大转化。

## 4. Patreon 配置（可选，面向海外）

1. 打开 https://www.patreon.com 注册创作者账号，创建 campaign（设置月订阅档位）。
2. 主页链接格式：`https://www.patreon.com/<你的创作者名>`。
3. 在 README「赞助与支持」章节填入该链接。

## 5. 填入 README 的写法（复制后替换链接）

在 `README.md` 末尾「开源与许可」章节后新增：

```markdown
## 赞助与支持

如果 text2script 帮到了你，欢迎请我们喝杯咖啡，支持持续维护与进阶功能（分镜拆解、提示词工厂、角色一致性）：

- [爱发电](https://afdian.com/a/<你的uid>)（国内推荐，支持月费会员）
- [GitHub Sponsors](https://github.com/sponsors/<你的用户名>)（开源赞助）
- [Patreon](https://www.patreon.com/<你的创作者名>)（海外订阅，可选）
```

填入真实链接后，自测：逐个粘贴到浏览器可打开、页面显示自己的创作者主页即配置成功。

## 6. 验证与复盘口径

- **可达性验证**：链接可匿名打开（无需登录即可看到主页/介绍）即为有效；爱发电可即时验证，海外渠道在可访问网络下验证。
- **T28 复盘口径**：记录各渠道上线日期与后续 2 周赞助笔数/金额，汇入 M5 运营复盘（开源 star ≥ 50 或教程播放 ≥ 1 万即进入付费/加码决策）。
