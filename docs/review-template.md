## 3. 复盘结论（回填后勾选）

- 需求信号（至少二选一达标）：
  - ☐ star ≥ 50
  - ☐ 教程播放 ≥ 1 万
- ☐ 达标 → **加码路径**：上架付费进阶版（分镜拆解，订阅 19–49 元/月或按量），
  评估投入视觉类模块（角色一致性 / 提示词工厂 / 运镜扩展）。
- ☐ 未达标 → **转向路径**：保留开源版作为流量入口，把重心转向教程与代制作服务，
  **不追加付费版投入**（开发清单第六节变现节奏）。

## 4. 后续优化方向候选（供达标后排序）

| 方向 | 说明 | 优先级建议 |
| --- | --- | --- |
| 角色一致性 | 跨镜角色外貌/服装保持一致（视觉类模块） | 高（若加码） |
| 提示词工厂 | 分镜表一键转出 AI 绘图提示词 | 中 |
| 运镜扩展 | 在 6 类运镜基础上增加组合运镜与镜头脚本模板 | 中 |
| 英文输出 | 覆盖海外创作者，配合 Patreon 变现 | 低（视海外流量） |
